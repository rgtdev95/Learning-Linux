# Linux Documentation Sources

No matter how experienced you are, you won't always know, or remember, exactly how to use every program and utility: which command to reach for, what options it takes, what output to expect, and so on. Consulting help documentation is an everyday part of working in Linux, not a sign of inexperience — even seasoned administrators do it constantly.

## Where Documentation Lives

Because Linux systems are assembled from a wide range of software sources, documentation lives in several different places, with more than one way to get help. One of the important jobs a Linux distribution does is gather all of this material and present it in a consistent, easy-to-use form.

The main sources of Linux documentation are:

| Source | Description |
| :--- | :--- |
| **The man pages** | Short for "manual pages" — the classic and most widely used reference, covering commands, configuration files, and programming interfaces |
| **GNU Info** | A more structured, cross-linked documentation system used by many GNU tools |
| **The `help` command and `--help` option** | Quick, built-in reminders of a command's usage, available right at the prompt |
| **Distribution-specific documentation** | Such as the Ubuntu Documentation, Fedora Documentation, or Gentoo Handbook, covering installation, configuration, and distro-specific features |
