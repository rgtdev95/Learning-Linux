# Changing the Desktop Background

One of the first things most users do when settling into a new system is personalize the desktop. Every Linux distribution ships with a default set of wallpapers, but you aren't limited to them. You can replace the default background with any image on your system, choose from additional built-in options, or set a solid color if you prefer a clean, distraction-free workspace.

## 1. Opening Background Settings

The quickest way to change the background is to right-click on an empty area of the desktop — a convention that will be familiar from both Windows and macOS. The exact option varies by environment:

| Desktop Environment | Menu Option |
| :--- | :--- |
| GNOME (Ubuntu, Fedora, RHEL, openSUSE) | **Change Background** → opens Settings → Appearance directly |
| KDE Plasma | **Configure Desktop and Wallpaper** |
| Cinnamon (Linux Mint) | **Change Desktop Background** |

On GNOME-based systems, background settings can also be reached directly through **Settings → Appearance**.

## 2. Background Options

Once in the background settings, there are three options:

- **Built-in wallpapers** — every distribution includes a curated selection. On Ubuntu, for example, GNOME's background settings include light and dark variants that can switch automatically based on the system's appearance mode.
- **Custom image** — browse the filesystem and select any image file. Common formats such as JPEG and PNG are fully supported.
- **Solid color** — most desktop environments allow the wallpaper to be replaced with a plain color, which some users prefer for its simplicity.

> [!NOTE]
> Comparable settings: **System Settings → Wallpaper** on macOS, or **Settings → Personalization → Background** on Windows.

# Changing the Desktop Theme

The **desktop theme** controls the overall visual style of the interface: window borders, buttons, menus, scrollbars, icons, and system fonts. Changing the theme is one of the most effective ways to alter how the system looks and feels without changing how anything works.

## 1. Theme Settings by Environment

| Desktop Environment | Location | Notes |
| :--- | :--- | :--- |
| GNOME | Settings → Appearance | Switch between light and dark modes, and on some distributions select an accent color. Deeper customization — icon themes, cursor styles, legacy GTK application themes — requires the **GNOME Tweaks** utility. |
| KDE Plasma | System Settings → Appearance | Comprehensive control over the global theme, window decorations, icon set, fonts, and cursor style, all from a single location, with a live preview before applying changes. |
| Cinnamon | System Settings → Themes | Separate controls for the desktop theme, window borders, icons, and mouse cursor. |

> [!NOTE]
> Comparable settings: **Settings → Personalization** on Windows, or **System Settings → Appearance** on macOS.

## 2. Additional Themes

Themes beyond the defaults are available from the **GNOME Extensions** website and from community resources such as **GNOME-Look.org**, which hosts a large library of user-created themes, icon sets, and cursors.
