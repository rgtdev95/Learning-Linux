# Desktop Environments

Unlike Windows or macOS, the Linux desktop isn't a fixed part of the operating system — it's a separate, interchangeable component called a **desktop environment (DE)**, and there are several to choose from. It's even possible to install and switch between multiple desktop environments on the same system. This is one of Linux's defining characteristics, and one of the first things that sets it apart from other operating systems.

## 1. Core Components

Every desktop environment is built around two core pieces, generally bundled together with a consistent set of applications and utilities to produce the seamless, unified experience users think of as "the desktop":

- **Session manager** — starts and maintains the elements of the graphical session.
- **Window manager** — controls how windows are displayed, moved, resized, and decorated on screen.

> [!NOTE]
> Components from different desktop environments can technically be mixed, but in practice most users work within a single, complete desktop environment.

---

## 2. GNOME

This course uses **GNOME** across all three Linux distribution families covered: Red Hat (Fedora, RHEL/CentOS), SUSE (openSUSE), and Debian (Ubuntu, Linux Mint). GNOME is the most widely deployed desktop environment in the Linux ecosystem and is the default on all of these distributions. Ubuntu 24.04, for example, ships with GNOME 46.

## 3. KDE Plasma

The other major desktop environment you're likely to encounter. **KDE Plasma** is more feature-rich and highly configurable, with a layout — taskbar along the bottom, application launcher, system tray — that will feel immediately familiar to users coming from Windows. KDE has traditionally been associated with SUSE and openSUSE, though openSUSE also offers a GNOME variant, which is the version used in this course.

## 4. Other Desktop Environments

| Environment | Known For |
| :--- | :--- |
| **XFCE** / **LXQt** | Lightweight environments designed for older or lower-powered hardware; practical when system resources are limited |
| **Cinnamon** | Default desktop on Linux Mint; traditional layout (taskbar along the bottom, start menu, system tray) that feels comfortable to users coming from Windows |
| **MATE** | A continuation of the older GNOME 2 interface, favored by users who prefer a more classical desktop experience |

> [!NOTE]
> If you're using any of these environments, your screen will look different from the examples shown in this course. That's entirely expected — the core concepts are consistent across all of them, and the workflows covered here translate directly regardless of which environment you're working in.
