# Viewing Files and Directories

## 1. View Modes

The file manager offers two primary view modes, which can be toggled at any time:

| View | Description |
| :--- | :--- |
| **Icons view** | Displays files and folders as visual thumbnails — useful for browsing images and media |
| **List view** | Displays files in a detailed list with columns for name, size, type, and modification date — generally more practical when working with large numbers of files |

| Action | Shortcut |
| :--- | :--- |
| Switch to Icons view | Toolbar icon, or `Ctrl+1` |
| Switch to List view | Toolbar icon, or `Ctrl+2` |

## 2. Sorting

Files can be sorted by name, size, type, or modification date. In Nautilus, click **View → Sort By** to select the preferred sort order.

> [!NOTE]
> This is equivalent to right-clicking and choosing "Sort by" in Windows Explorer.

## 3. Hidden Files

Files and directories whose names begin with a period (`.`) are hidden by default, since they typically contain configuration data that most users don't need to interact with directly.

| Action | Shortcut |
| :--- | :--- |
| Show hidden files | `Ctrl+H`, or **View → Show Hidden Files** |

> [!NOTE]
> Once revealed, you'll notice a significant number of hidden files and folders in your home directory — these store personal settings for applications and the desktop environment itself.

## 4. Zooming (openSUSE)

The zoom level of icons in the file manager can also be adjusted via **View → Zoom In** and **View → Zoom Out**, which is helpful when working with image-heavy folders.

## 5. Additional View Options (Supplementary)

- **Properties** — right-click a file or folder → **Properties** to see its size, location, permissions, owner, and timestamps.
- **Quick preview** — select a file and press **Space** to preview its contents without opening the full application.
