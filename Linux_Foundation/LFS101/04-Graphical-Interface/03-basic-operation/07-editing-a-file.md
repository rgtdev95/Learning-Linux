# Editing a File

## 1. Opening a File for Editing

To open and edit a text file, simply double-click it in the file manager. Linux opens it with the default application associated with that file type.

## 2. The Default Text Editor on GNOME

The default text editor on GNOME is **gedit** (also known as **Text Editor** in recent versions) — a clean, general-purpose editor that handles everyday editing tasks well, including:

- Syntax highlighting for code
- Spell checking
- Line numbering

It's a practical tool for editing configuration files, making quick notes, or writing scripts.

> [!NOTE]
> Text editors are covered in much greater depth later in the course, including both graphical and command-line options.

## 4. Opening With a Different Editor (Supplementary)

Right-click the file → **Open With** → choose a different application, either for that one occasion or as the new default (see [Setting Default Applications](03-setting-default-applications.md)).

## 5. Saving Changes (Supplementary)

`Ctrl+S` saves the file. Editors will generally prompt for confirmation if you try to close a document with unsaved changes.
