# Launching Applications

## Basic Operations (Section Overview)

Even experienced users occasionally forget the exact name of an application or where to find it. The graphical desktop makes this a non-issue: applications are easy to locate and launch without needing to remember a single command. This section covers the everyday tasks you'll perform most often when working in a Linux graphical environment.

## 1. Launching Applications by Desktop Environment

Where you find and launch applications depends on which desktop environment you're using, but the concept is the same across all of them: there's a central place to access everything installed on the system, organized so browsing and searching are both straightforward.

| Desktop Environment | How to Launch |
| :--- | :--- |
| **GNOME** (Ubuntu, Fedora, openSUSE, RHEL) | Select **Activities** in the upper-left corner, or press the **Super** key, to open the Activities Overview — a search bar at the top plus a grid of open windows. Start typing an application's name and results appear immediately; this is generally the fastest way to launch something. The grid icon at the bottom of the screen opens the full application grid to browse everything installed. |
| **Ubuntu** (specifically) | Works the same as GNOME above, plus a persistent sidebar **dock** on the left where frequently used applications can be pinned for quick access — comparable to the Taskbar on Windows or the Dock on macOS. |
| **KDE Plasma** | Select the **Application Launcher** in the lower-left corner of the taskbar, similar in concept to the Start menu on Windows. Applications are organized into categories, with a search bar at the top. |
| **Cinnamon** (Linux Mint) | Select the **Menu** button in the lower-left corner. Applications are organized by category with a search field at the top — a layout users coming from Windows will find immediately familiar. |

> [!TIP]
> Regardless of environment, the keyboard-driven search approach — open the launcher, start typing — is the most efficient method and is worth making a habit of early on.

## 2. What Comes Pre-Installed

One of the first things new Linux users notice is how much software comes ready to use out of the box. A standard installation typically includes a web browser, an office suite, a media player, a file manager, a text editor, and a range of system utilities — enough to handle most everyday tasks without installing anything additional.

| Category | Typical Application(s) | Notes |
| :--- | :--- | :--- |
| Web browser | **Firefox** | Default on many distributions, including Ubuntu and Fedora. **Chromium** (the open-source base of Google Chrome) is available in most software repositories. Proprietary browsers such as Chrome and Opera can also be downloaded and installed directly. |
| Office suite | **LibreOffice** | Included by default on most distributions; provides compatible equivalents to Microsoft Word, Excel, and PowerPoint. |
| Email client | **Thunderbird** | Common across many distributions. |
| Media playback | **Rhythmbox** (audio), **Totem** (video) | Typical defaults on GNOME-based systems. |
| File manager | **Nautilus** (Files) on GNOME, **Dolphin** on KDE, **Nemo** on Cinnamon | Serves the same role as File Explorer on Windows or Finder on macOS. |

> [!NOTE]
> Beyond what's pre-installed, Linux software repositories contain thousands of additional applications that can be installed in a few clicks through the software center or package manager — covered in detail later in the course.
