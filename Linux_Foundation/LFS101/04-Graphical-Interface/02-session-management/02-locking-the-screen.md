# Locking the Screen

Locking the screen protects an active session from casual access while stepping away, without ending the session the way logging out does.

## 1. Why Lock Instead of Log Out

- **Logging out** ends the session — open applications close and unsaved work can be lost.
- **Locking** freezes the display behind a password prompt while everything keeps running in the background exactly as you left it.

## 2. How to Lock the Screen

| Method | Detail |
| :--- | :--- |
| Keyboard shortcut | **Super + L** on GNOME (the most common cross-distribution shortcut) |
| System menu | Click the top-right system menu → **Lock** |
| Automatic | The screen locks on its own after a configurable period of inactivity (see the next lesson) |

> [!NOTE]
> On KDE Plasma, the default lock shortcut is often **Ctrl + Alt + L**, and is configurable under System Settings → Shortcuts.

## 3. What You See

The lock screen typically shows the clock, date, and any notifications, without revealing the desktop contents. Pressing a key or moving the mouse reveals a password prompt to return to the session.
