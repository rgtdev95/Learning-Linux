Whether you need to edit photos, create vector graphics, design layouts for print, or paint digitally, you can find powerful, free applications to handle the job. If you are coming from Windows or macOS, you will find that most industry-standard design tools have a close equivalent natively available on Linux.

GIMP (GNU Image Manipulation Program)

GIMP (GNU Image Manipulation Program) is the primary raster image editor on Linux and the closest open source equivalent to Adobe Photoshop. It supports all common image formats, including JPEG, PNG, GIF, and TIFF, and provides a comprehensive set of tools for photo retouching, compositing, and image creation.

Key features of GIMP include:


Full support for layers, channels, masks, and paths


High bit-depth processing up to 32-bit float per color channel, addressing a historical limitation compared to Photoshop


An extensive library of filters and effects


Support for plugins, allowing the tool to be extended with additional functionality


Scriptable automation through Script-Fu and Python

GIMP is available on all major Linux distributions and can be installed from the standard repositories. For users transitioning from Photoshop, the interface and workflow differ, but the core capabilities are comparable for most everyday image editing tasks.

Krita

A professional, open source digital painting and illustration application. Widely considered the gold standard for digital art on Linux, featuring an advanced brush engine, full CMYK support, and tools tailored for concept artists, illustrators, and texture artists. While GIMP focuses on photo manipulation, Krita excels at original digital artwork creation.

Inkscape

A professional vector graphics editor, comparable to Adobe Illustrator. Works with the SVG format natively and supports layers, transformations, and complex path operations. The standard tool for logo design, illustrations, and technical diagrams on Linux.

Scribus

A desktop publishing application for creating print-ready documents, brochures, and layouts. Supports professional publishing features such as color separation and PDF export. Comparable to Adobe InDesign for desktop publishing tasks.

GNOME Image Viewer (Loupe)

The default image viewer on current GNOME-based distributions, including Ubuntu 22.04+ and Fedora 39+. Replaces the older Eye of GNOME (eog). Supports basic viewing, zoom, and directory browsing.

Shotwell

A photo management and organization application for GNOME, similar in scope to Apple Photos. Supports basic editing, tagging, and library management.

ImageMagick

A suite of command-line tools for batch image processing. The magick command (historically convert in older versions) handles format conversion, resizing, cropping, and effects, making it particularly useful for scripting and automation tasks. Note that on ImageMagick v7 and later, magick or magick convert should be used in place of the legacy convert command, which is deprecated.
