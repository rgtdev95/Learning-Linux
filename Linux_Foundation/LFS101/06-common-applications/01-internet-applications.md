Overview

Linux provides a full range of network-aware applications for everyday internet use. Whether you are browsing the web, managing email, transferring files, or communicating with colleagues, there is a well-supported application available for every task.

The main categories of internet applications covered in this section are:

Web browsers

Email clients

File transfer tools

Messaging and conferencing applications

Web Browsers

As discussed in the “Graphical Interface” chapter, Linux supports a wide range of web browsers. Most users will find their preferred browser is either available directly or can be installed from the software repositories.

Select the plus (+) sign next to the option name to learn more about commonly available browsers.


Firefox
This is the default browser on many distributions, including Ubuntu and Fedora. It is open source, actively maintained, and fully featured.


Google Chrome & Microsoft Edge
These are proprietary browsers available as .deb or .rpm packages. They offer full synchronization with their respective ecosystem accounts.


Chromium
It is the open source foundation on which Chrome is built. Available in most software repositories and functionally very similar to Chrome, without Google's proprietary additions.


GNOME Web (Epiphany)
This is a lightweight browser integrated with the GNOME desktop, suitable for everyday browsing with a minimal interface.


Opera
It is a proprietary browser with a built-in VPN and ad blocker, available for download from Opera's website.


Konqueror
This is a browser and file manager integrated with the KDE desktop environment.


Text-based browsers
For terminal use, options such as lynx, links, and w3m allow basic web browsing without a graphical interface. These are rarely used for everyday browsing, but are useful in server environments or when troubleshooting without a GUI.

Email Applications

Linux supports a wide range of email clients, from full-featured graphical applications to lightweight terminal-based tools. Many users also access email entirely through a web browser, which requires no additional software.



Email Applications

All email clients on Linux use standard protocols to communicate with mail servers. IMAP (Internet Message Access Protocol) keeps messages stored on the server and synchronized across devices; this is the current standard for most personal and business email. POP3 (Post Office Protocol) downloads messages to the local machine and is less commonly used today. Most clients also support sending mail via SMTP (Simple Mail Transfer Protocol).

Graphical email clients provide a familiar interface comparable to Microsoft Outlook or Apple Mail:

•
Thunderbird is a widely used graphical email client managed by MZLA Technologies (a Mozilla Foundation subsidiary). It supports IMAP, POP3, and modern OAuth2 authentication, includes a calendar and task manager, and has a large library of extensions. It is available on all major distributions and is the default email client on many of them.

•
Evolution is a full-featured email and personal information manager that integrates email, calendar, contacts, and tasks. It supports Microsoft Exchange connections, making it a practical choice in enterprise environments that use Microsoft infrastructure.

•
Claws Mail is a lightweight, fast email client suited for users who prefer a simpler interface with lower resource usage.

Text-based email clients operate entirely in the terminal:

Mutt is a powerful, highly configurable terminal email client favored by advanced users who work primarily in the command line.

mail is a basic command-line tool for sending and reading email, primarily used for scripting and automation rather than everyday correspondence.

Web-based email services, including Gmail, Yahoo Mail, and Microsoft Outlook/Office 365,  work in any Linux browser exactly as they do on other operating systems and require no additional configuration.
