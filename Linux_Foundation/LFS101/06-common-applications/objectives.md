Learning Objectives

By the end of this chapter, you should be able to:

•
Identify the most widely used internet applications on Linux, including web browsers and email clients.

•
Use LibreOffice and other office productivity tools to handle everyday document, spreadsheet, and presentation tasks.

•
Recognize the key developer tools available on Linux, including compilers, debuggers, and version control systems.

•
Identify common multimedia applications for audio and video playback, editing, and management.

•
Use GIMP and other graphics utilities for image editing and graphic design tasks.
