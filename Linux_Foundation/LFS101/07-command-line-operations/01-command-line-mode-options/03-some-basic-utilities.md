# Some Basic Utilities

A few commands appear often enough that they're worth introducing now, briefly, before covering them in more depth later:

| Command | Description |
| :--- | :--- |
| `cat` | Displays a file's contents (or combines/concatenates multiple files together) |
| `head` | Displays the first few lines of a file |
| `tail` | Displays the last few lines of a file |
| `man` | Opens a command's documentation page (man page) |

> [!NOTE]
> You'll also see the pipe symbol (`|`), which takes the output of one command and feeds it as input into another. It's one of the more useful features of the shell, and it behaves identically regardless of distribution.
