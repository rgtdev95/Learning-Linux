# Network Configuration

## 1. What Network Manager Handles

**Network Manager** handles the full range of connection types a desktop or laptop user is likely to encounter:

- Wired Ethernet
- Wi-Fi
- Mobile broadband
- Virtual Private Networks (VPN)

It also manages **connection profiles** — the settings for networks previously connected to — so they reconnect automatically when available.

> [!NOTE]
> For the vast majority of users and situations, Network Manager should be the only tool needed for network configuration. Manual file editing is reserved for advanced scenarios, such as server environments or highly specific network configurations, and is covered later in the course.
